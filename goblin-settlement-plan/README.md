## 用户已经确定的方向

- 玩家长期住在聚落旁边，观察并参与它的成长；远离时暂不要求聚落继续发展。
- 先做一个种族：哥布林。包含男女、成人与儿童，正常繁衍。
- 初期繁衍意愿强，中期出生总量达到高峰；后期逐渐降低，城镇足够大时允许降到零。
- 领地范围和扩张速度受人口约束。扩张需要真实生产、施工和地形判断。
- 有职业、工具、少量随身物品空间和以真实箱子为主的仓储；玩家能够偷取箱内资源。
- 可以建造、扩建和升级房屋，修路、升级道路、建桥；后期更重视生活品质。
- 守卫傀儡顺序：木、石、原版铁、金、钻石、黑曜石；黑曜石最高级。
- 必须保护玩家在聚落附近或内部的房屋与地块。
- 先形成一套独立 Fabric 模组，用一个安装包发布；代码按职责分开。
- 日常 AI 开发以 Sol 中等推理为默认，范围明确的任务使用 Luna，更强模型留给关键审查和复杂故障。

## 仍属于建议初值

初始 8 名成年人、单镇 64 人上限、8×8 格规划地块、各阶段时长、道路与桥梁尺寸、傀儡名额、具体建筑材料与配方，均在两份计划中标为**建议初值**。它们尚未经过游戏测试，不能当作已经最终确定的平衡数值。

工程已配置 Minecraft Java 1.21.11、Fabric Loader 0.19.2、Fabric API 0.141.4+1.21.11、Loom 1.14.10、官方 Mojang 映射与 Java 21 编译目标；本机离线构建已通过，验证范围与限制见 CURRENT_STATUS.md。
