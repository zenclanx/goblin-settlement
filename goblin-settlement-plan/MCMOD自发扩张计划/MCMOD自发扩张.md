可以，现在这个方向已经很明确了：**玩家长期住在哥布林聚落旁边，看着他们繁衍、劳动、修房、铺路、架桥，最终从营地发展成规模有限、生活越来越精致的小城镇。**

你对区块的理解基本正确，但需要区分“能看见、已加载”和“正在模拟生物活动”。模拟距离会影响实体更新；另外，Java 1.21.9 已经取消了固定出生点区块的常驻机制。远处发展也可以另做简化结算，不过我们这次就采用**活动范围内正常发展，离开后暂停，回来继续**的设计。[模拟距离说明](https://www.minecraft.net/en-us/article/minecraft-snapshot-21w38a)、[区块加载变更](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-9)

下面是完整设计初稿。**哥布林种族、自然繁衍、人口限制扩张、道路桥梁、房屋升级、真实箱子，以及六级傀儡，是已经确定的方向；具体人数、时间、尺寸和配方属于建议初值，以后试玩时调整。这轮只制定计划。**

1. **整个模组围绕一个可以持续运转的生活循环展开。**

   基本循环是：

   **采集与种植 → 搬运入库 → 制作食物、工具和建材 → 修建住房与交通 → 支持出生和成长 → 增加劳动力 → 扩大生产。**

   人口接近上限以后，循环转为：

   **稳定生产 → 维护设施 → 改建住房 → 改善交通与防御 → 增加休闲和公共空间。**

   城镇始终有事情做，但不会因为资源越来越多，就无限生孩子、无限造房子、无限圈地。库存充足以后，居民会减少生产，增加休息和社交。

   玩家可以长期旁观，也可以通过交易、提供材料、修建公共设施、保护居民影响发展。聚落日常运行应当能够自行完成。

2. **最初自然生成一个有基本生存能力的哥布林营地。**

   推荐初始规模为 **8 名成年哥布林，男女各 4 名**。生成时优先选择附近有水、树木、可耕地和安全地面的地点。

   初始营地包含临时住所、公共箱子、营火和少量启动物资：口粮、种子、树苗、基础工具和铺盖。居民随后自行修建正式设施。

   这些物资只在营地创建时提供一次。箱子被偷空、居民死亡或者营地遭到破坏，都不会通过反复刷新补回资源。

   聚落生成时登记固定身份，避免玩家反复进出区块刷出新居民。其他自然营地与它保持较大间隔，初值可设为 **512 格以上**；多个聚落共用可配置的世界人口预算，防止长期探索积累过多居民。

3. **哥布林采用少量基础外形，通过年龄、服装和工具表现差异。**

   外形建议是绿皮、尖耳、较大的鼻子，身高比玩家矮一些，整体保持 Minecraft 方块风格。

   成年男女共用主要骨架，通过脸形、发型、声音和少量服装区别表现。男女可以担任相同职业，工作能力不按性别区分。儿童拥有更矮的体型和不同的动作，不参与繁衍、危险采矿和战斗。

   第一套美术可以控制在：

   - 一套成年主体模型，少量男女外观差异。
   - 一套儿童体型与动作。
   - 三四种肤色、少量脸形和发型。
   - 一组可以叠加的职业服装与配饰。
   - 行走、工作、搬运、进食、休息、惊慌、交谈等共用动作。

   居民拥有名字、家庭、住所、职业和简单偏好。白天工作，晚上回家；空闲时去广场、树下或营火旁聚集。儿童可以玩耍、跟随家人、围观施工，让村庄有生活感。

4. **职业保持清晰，但允许居民根据需要兼职。**

   | 职业 | 主要工作 | 外观识别 |
   |---|---|---|
   | 农民 | 种植、收获、补种，兼任采食和基础烹饪 | 草帽、锄头 |
   | 林工 | 伐木、补种、管理林地 | 斧头、肩带 |
   | 矿工 | 采石、开矿、勘查安全矿道 | 头灯、镐 |
   | 建筑工 | 房屋、道路、桥梁、修缮 | 工具腰带 |
   | 搬运员 | 仓库整理、工地供料、分仓运输 | 背包、货物 |
   | 工匠 | 制作工具、冶炼、维修、制造傀儡 | 围裙、护目镜 |
   | 哨卫 | 巡逻、报警、组织撤离、有限自卫 | 头盔、盾牌 |

   初期一人可以兼任多个工作，工坊和人口增加以后才逐渐专业化。职业熟练度缓慢提高，但转岗不会让居民失去基本劳动能力。

   调度上始终保留食物生产和运输能力。缺粮时先调回劳动力，缺工具时优先恢复工具生产，不能全村都去修大房子。

   哥布林哨卫主要负责警戒与组织，傀儡承担主要战斗。这样既有职业社会，也不会让普通居民整天追着怪物跑。

5. **人口增长采用你要求的“初期意愿高、中期总量快、后期归零”。**

   建议单镇人口上限先设为 **64 名，包含儿童**。孕育中的孩子提前预占名额，防止多人同时出生突破上限。

   繁衍需要同时满足：

   - 有符合条件的成年男女伴侣。
   - 有可供新成员使用的住房位置。
   - 食物有稳定余量。
   - 居民健康，聚落没有处于紧急避难状态。
   - 人口名额尚未用满。

   建议的繁衍意愿倍率为：

   **意愿倍率＝max〔0，1－已占用人口名额 ÷ 64〕。**

   全镇的繁衍进度，则受到成年人口数量影响：

   **每分钟繁衍进度＝0.01 × 当前可参与的成年人口 × 意愿倍率 × 生活条件系数。**

   进度满 1 后，为一组符合条件的伴侣安排一次孕育，并预留人口与床位。没有合适伴侣时，最多保留一次进度，避免条件恢复后突然集中出生。

   在全员成年、没有待出生孩子、生活条件充足的理想情况下，趋势如下：

   | 当前人口 | 意愿倍率 | 每 10 分钟增加的繁衍进度 |
   |---:|---:|---:|
   | 8 | 87.5% | 0.70 |
   | 16 | 75% | 1.20 |
   | 32 | 50% | 1.60 |
   | 48 | 25% | 1.20 |
   | 60 | 6.25% | 0.38 |
   | 64 | 0% | 0 |

   这样，初期每个家庭的繁衍倾向高；中期成年人口增加，全镇出生数量更高；后期逐渐放缓，满额后停止。

   这张表表达的是理想趋势。实际出生速度还会受到儿童比例、住房、休养和食物影响。

6. **孩子成长需要时间，人口损失以后也有恢复空间。**

   初步建议：

   | 项目 | 建议初值 |
   |---|---|
   | 孕育时间 | 10 分钟有效模拟时间 |
   | 儿童成长 | 60 分钟有效模拟时间 |
   | 生育后家庭休养 | 30 分钟有效模拟时间 |
   | 开始繁衍所需食物储备 | 至少覆盖未来 30 分钟需求 |
   | 生活条件系数达到满值 | 食物覆盖未来 60 分钟需求，并满足其他条件 |

   有效模拟时间只在相关系统实际运行时累计，睡觉跳过夜晚、修改时间、退出存档都不会直接完成孕育或成长。

   儿童消耗食物和床位，但不立即提供劳动力，也不增加领地额度。成年后才进入工作分配。

   第一版建议暂时不加入自然老死，以免玩家刚建立感情，整代居民就集中消失。战斗和事故仍可能造成死亡。人口低于上限后，只要生活条件恢复，繁衍也会恢复。

   家庭记录可以保留父母关系，避开直系亲属和同父母兄弟姐妹配对；暂不做复杂遗传系统。极端灾难造成无法继续繁衍时，聚落可以维持生活或逐渐荒废，重建作为玩家可选操作。

7. **领地大小由成年人口提供额度，实际扩张还要看需求和能力。**

   建议把可开发土地划成 **8×8 格的小地块**，初始公式为：

   **可开发地块上限＝4＋2×成年哥布林人数。**

   | 成年人数 | 地块额度 | 最大开发面积 |
   |---:|---:|---:|
   | 8 | 20 块 | 1,280 平方格 |
   | 16 | 36 块 | 2,304 平方格 |
   | 32 | 68 块 | 4,352 平方格 |
   | 64 | 132 块 | 8,448 平方格 |

   这些是允许开发的上限，聚落没有必要用满。住房、农田、道路、工坊、专用林地和工作营地都需要占用额度。发现一个远方矿点，不会自动获得沿途大片领地。

   实际外扩必须满足：现有可用空间不足、食物有余量、交通可达、材料足够、有空闲劳动力。优先填补村内空地，再考虑向外延伸。

   扩张速度也随劳动力变化。可先设为**每 20 分钟最多新增 `成年人数÷8` 向下取整个地块，最多 4 块**；这是施工许可上限，缺材料时仍然不会完成建设。

   开发区域还设置距聚落中心 **96 格**的初始距离上限，避免沿着河流拉成一条很长的村庄。较低模拟距离下，实际开发会优先集中在可活动范围内。

   人口减少时，停止新增用地，逐渐停用外围闲置设施。现有房子和道路不会因为人口下降突然被拆掉。

8. **资源真实存在于居民背包、箱子和工地之间。**

   成年居民建议有 **6 格随身物品空间**，另外设置工具与装备位置。携带空间受到限制，主要库存留在公共箱子里。

   工作流程应当看得见：

   **领取工具 → 前往工作地 → 获取物品 → 装入背包 → 返回仓库或工地 → 实际存放、加工或施工。**

   仓库使用玩家可以打开、拿取和破坏的真实箱子。聚落可以记录库存，但记录本身不能产生物品。

   仓储逐渐分成食物、建材、工具、矿物几类。远处工作量增加后，可以设置小型分仓，减少所有人都挤在一个箱子前。

   工程立项时预留材料，施工时逐批领取和消耗。玩家拿走已经预留的木头后，工程会缺料、重新安排采集或暂时停工，不会照样凭空完工。

   仓库满了就减少生产或扩建合理容量。后期设定库存目标，避免无限制造工具、无限砍树、无限堆箱子。

9. **生产链必须能够从基础工具一路发展到高级材料。**

   主要生产链定为：

   | 生产链 | 输入与产出 | 需要保留的关键资源 |
   |---|---|---|
   | 农业 | 种子、耕地、水源 → 作物 → 食物 | 下一轮种子与应急口粮 |
   | 林业 | 树苗 → 树木 → 木材 → 木板、木棍、木炭 | 补种树苗与基础木材 |
   | 基础制造 | 木材、石材 → 工具、工作台、炉具 | 两套基础工具的备用材料 |
   | 冶炼 | 矿石、燃料 → 金属 → 工具与部件 | 农具、矿镐和维修用料 |
   | 建筑 | 原料 → 建材 → 住房、道路、桥梁 | 必要维修与应急修路材料 |
   | 防御 | 木石金属、部件 → 傀儡 → 维修和升级 | 维持现有守卫的材料 |

   居民使用工具并消耗耐久。出发前检查工具和背包，低耐久时更换或维修。

   工具全部丢失时，应当能够退回基础生产：低效徒手获取木材，重新制造木工具，再恢复石工具。不能出现“没斧头就拿不到木头，没木头就造不出斧头”的永久停摆。

   砍树后补种，收获后留种。矿石按真实储量消耗；附近稀有矿不足时，居民可以勘查可达区域、降低工具档次，或通过交易取得材料。

   **高级发展允许停在资源条件能够支持的阶段。** 没有钻石的聚落，仍然可以耕作、生活、维护道路和升级普通住房。

10. **聚落按明确的优先级安排工作，遇到短缺能够调整。**

    建议默认优先级是：

    **避险救援 → 食物与补种 → 基础工具 → 关键交通和设施维修 → 必要住房 → 扩张工程 → 傀儡升级 → 装饰与品质改建。**

    优先级也考虑具体情况。例如通往唯一农田的桥断了，修桥就属于恢复食物生产；普通观景桥可以继续等待。

    每名居民同时承担一个主要任务。任务需要占用明确的工作地点和材料，避免多人同时争抢同一棵树、同一个箱子槽位或同一处施工位置。

    连续失败的任务会暂时降级，记录原因并选择其他工作。居民不会在悬崖边、被堵住的门口或空箱子旁无限重复动作。

    标准模式下，短期饥饿先降低效率、暂停繁衍和建设，同时保留基本自救能力。更严酷的饥荒死亡机制可以作为以后可选的难度设置。

11. **房屋从简陋住所发展为有家庭和历史的建筑。**

    | 住宅阶段 | 外观与结构 | 主要作用 |
    |---|---|---|
    | 临时住所 | 铺盖、简易棚顶、少量储物 | 度过创业期 |
    | 基础木屋 | 完整墙体、屋顶、门、照明 | 稳定居住 |
    | 扩建住宅 | 增加房间、侧屋或二层 | 容纳家庭成长 |
    | 优质住宅 | 更好的墙体屋顶、家具、庭院 | 提升舒适与生活质量 |
    | 成熟街区住宅 | 协调沿街立面、门廊、景观 | 形成城镇风格 |

    “增加容量”和“改善品质”分开处理。人口满额以后，住宅仍可以变漂亮，增加家具与庭院，不会因为房子升级又突破人口上限。

    建造采用基础结构与可组合部件，入口位置、屋顶形式、材料和附属房间允许变化。哥布林建筑风格可以保留木梁、石基、外露连接件和略微不对称的轮廓，后期再逐渐整齐。

    建筑选址时预留适量改建空间。开工顺序是准备地基、运输材料、逐步砌墙、封顶、布置内部、验收入住。

    改建前确认材料与临时住处，按区域施工，避免拆掉唯一住房以后才发现没材料。

    公共设施随着需要出现：仓库、农田、工坊、厨房、傀儡工坊、巡逻点、广场、交易摊位。设施必须提供实际用途，不能只为了填地图而建。

12. **道路是聚落规划的骨架，修建依据是实际交通需求。**

    最早连接公共仓库、住所、农田和采集点。以后再连接工坊、矿场、分仓、桥梁与广场。

    路线选择综合考虑路程、坡度、施工材料、危险、耕地损失和玩家保护区。允许弯曲，尽量减少连续跳跃和不必要的削山填谷。

    道路初值可以分为：

    | 等级 | 建议通行净宽 | 适用位置 |
    |---|---:|---|
    | 初期步道 | 2 格 | 住宅与小型工作点 |
    | 普通常用道路 | 3 格 | 农田、仓库、工坊之间 |
    | 城镇主街 | 5 格 | 主运输方向、广场和主要桥头 |

    居民活动频繁、运输耗时明显或持续拥堵时，才考虑升级道路。处理拥堵时先增加会车位置、调整出工时间或设置分仓，再评估拓宽。

    大型傀儡使用满足宽度和净高要求的路线，避免卡在小门、低檐和窄巷里。普通住宅内部可以不供大型傀儡进入。

    后期道路会补充照明、台阶、边缘整理和路口空间。拓宽需要重新检查地块与建筑，不能为了把路修直就拆掉玩家房子。

13. **桥梁作为独立工程设计，从选址到验收都要完整。**

    桥梁立项需要确认：

    - 对岸确实有值得连接的农田、土地或资源。
    - 两端都能接入可通行道路。
    - 河宽、岸高和基础条件在当前工程能力内。
    - 材料和施工劳动力足够。
    - 不占用玩家保护区。

    初期优先选择窄河段。木桥可先支持约 **4～12 格跨度**；石桥和加强桥逐步支持更长跨度，例如 **12～24 格**。这些尺寸对应预先验证过的结构，超出范围就继续寻找其他过河点。

    桥梁施工顺序为：

    **两岸引道 → 桥台与必要支撑 → 桥面 → 护栏 → 照明 → 连通验收。**

    工人必须有安全站立位置，必要时搭建临时施工通道。未完成桥梁不对普通交通开放。材料不足时保留安全工地，工人转做其他任务。

    桥面宽度依据用途确定，主运输桥需要允许搬运居民和傀儡通过。跨河桥还应尽量保留水面通行空间。

    桥被破坏后先禁行，再安排修复；居民会使用已知安全绕路，没有绕路就暂停受影响运输。第一套完整设计暂定以河流、小峡谷和浅水工程为主。

14. **不同地形对应不同发展动作，无法处理时允许放弃那个方向。**

    | 地形 | 聚落的应对方式 |
    |---|---|
    | 平原 | 紧凑住宅与连续农田，减少零散占地 |
    | 森林 | 选择性伐木、补种、保留林业区，围绕大树布局 |
    | 河谷 | 优先沿同一河岸发展，需求明确后再架桥 |
    | 丘陵 | 小台地、台阶路、局部挡土结构 |
    | 高山 | 缩小单栋建筑，采用分层街区，限制大规模削山 |
    | 沙漠 | 靠近水源，先保障粮食和木材供应，增加当地材料使用 |
    | 雪地 | 加强照明和遮蔽，保护耕作条件，清理重要通道 |
    | 冰川 | 寻找稳定陆地，避免把主要住宅建在不可靠冰面上 |
    | 沼泽 | 抬高地板、短栈道，避开深水和复杂湿地 |
    | 海岸 | 沿海岸陆地发展，可建小码头作为后续设施 |
    | 大海 | 停止陆地外扩，寻找其他陆路方向 |
    | 峡谷、熔岩、危险洞口 | 标记危险，绕行或封闭接近路线 |

    初始选址可以偏向易生存地形；扩张过程中再体现复杂地形处理能力。

    每次选址同时检查地面支撑、坡度、上方空间、地下危险和道路入口。地形调整设置上限，例如普通住宅优先只接受少量填垫或挖除。

    一条路走不通时，聚落可以换方向、缩小建筑或转向村内升级。发展暂停应当有可理解的原因。

15. **傀儡按你确定的六级顺序发展。**

    **木 → 石 → 铁 → 金 → 钻石 → 黑曜石。**

    | 等级 | 定位 | 材料与发展依赖 | 外观方向 |
    |---|---|---|---|
    | 木傀儡 | 初期巡逻，抵挡小规模威胁 | 木材与基础核心 | 木框架、粗绳、木面罩 |
    | 石傀儡 | 更耐打的工地与营地守卫 | 石材与改进核心 | 石块护甲、厚重双臂 |
    | 铁傀儡 | 稳定的主力防御 | 沿用原版铁傀儡的基础材料体系 | 使用原版铁傀儡 |
    | 金傀儡 | 更高级护卫，可提供小范围支援 | 铁制结构、黄金、红石核心 | 金色护甲、明亮核心 |
    | 钻石傀儡 | 高攻击、较强机动和救援能力 | 高级核心、钻石部件 | 钻石护面、锐利轮廓 |
    | 黑曜石傀儡 | 最高综合战力，镇守核心区域 | 黑曜石装甲、钻石与高级核心 | 黑色重甲、暗紫纹路 |

    金傀儡强于铁傀儡，设定原因是更先进的核心与结构。黑曜石傀儡拥有最高防护和综合战力，代价是昂贵、移动较慢。

    初期建议按成年人口增加傀儡名额：**每 8 名成人约提供 1 个名额，最少 1 个，最多 8 个；黑曜石傀儡最多 1 个。** 傀儡不参与繁衍，也不增加领地额度。

    哥布林哨卫另外按约每 12 名成人安排 1 名，最多 4 名，他们仍计入居民人口。

    升级消耗材料，保留名字和归属，并占用原有名额。低级傀儡可以继续负责次要区域，居民不会达到新阶段就立即报废所有旧守卫。

    关键材料顺序必须明确：**获得铁工具 → 开采钻石 → 先制作钻石镐 → 采集黑曜石 → 制造最高级傀儡。** 工坊会预留关键工具材料，不能把所有钻石提前花在傀儡上。

    铁傀儡需要额外衔接哥布林聚落的归属、警报和敌我规则，不能假设原版行为会自动理解这一套社会关系。

16. **防御以保护居民和设施为目标，战斗范围受到控制。**

    夜间和警报期间，儿童与非战斗居民前往安全建筑。哨卫报警，附近傀儡优先拦截正在威胁居民的目标。

    守卫不因为玩家拿着武器、路过仓库或住在附近就发动攻击。

    巡逻围绕住宅、仓库、工地、桥头和外部工作点展开。遇到威胁时优先保护人员，其次保护关键物资和交通。

    追击设置范围限制，避免所有傀儡追着一个敌人跑出很远，留下空城。傀儡受损后回工坊维修，材料不足时调整巡逻安排。

    第一套防御设计以现有世界威胁为主。居民已经需要处理生产与建设，额外的周期性大规模攻城可以留作后续难度内容。

17. **玩家通过“宅地界桩”明确保护自己的房屋和地下空间。**

    推荐提供一个便宜、容易制作的界桩工具。玩家选择两个角，登记自己的宅地，也可以拼接多个区域。

    默认保护范围包含该地块的全部高度，覆盖屋顶、地下室和地下通道，并留少量边缘缓冲。

    在宅地内，哥布林不得擅自：

    - 拆除或放置方块。
    - 挖矿、伐木、平整地形。
    - 改动液体、农田或道路。
    - 使用玩家箱子里的物资。
    - 为扩建城镇搬走玩家建筑。

    玩家可以分别开放“允许通行”“允许使用指定箱子”“允许建设”等权限。允许通行不等于允许改建，捐赠一箱材料也不等于捐出整栋房子。

    **保护检查要同时作用于规划和实际施工。** 即使一座桥早已立项，玩家后来划出了宅地，施工也必须停止并重新规划。

    辅助保护包括记录模组运行后玩家新放置的方块，以及避让已有容器、红石和疑似建筑区域。不过，旧建筑无法仅凭外观可靠判断所有权，明确圈地才是保护依据。

    玩家可以在村内登记住宅。哥布林会把它作为需要保留的邻居宅地，道路绕行或接到玩家允许的入口。

18. **箱子可以偷，偷窃会影响资源与关系，但守卫不会凭空知道是谁。**

    公共仓库标明所属聚落。玩家打开箱子本身不算偷窃，实际拿走未获授权的物品才进入判断。

    建议采用以下反应：

    | 行为 | 聚落反应 |
    |---|---|
    | 获准领取、正常交易 | 无惩罚 |
    | 无人目击的物资丢失 | 发现短缺，补货并加强仓库巡逻 |
    | 被目击的小额初犯 | 警告，允许归还 |
    | 反复偷窃或盗走贵重物资 | 降低信任、暂停交易、驱赶 |
    | 攻击居民或严重破坏 | 守卫介入战斗 |

    目击需要合理距离、视线和对应行为。通过箱子库存变化发现短缺，不会自动把罪责算到最近的玩家头上。

    另设捐赠箱和交易箱，方便玩家正常提供资源。偷走的材料会真实影响建设：木头丢了，房子停工；粮食丢了，繁衍放缓；维修材料丢了，傀儡可能暂时不能恢复。

    关系可以修复。玩家归还物资、补偿损失、完成协作请求后，逐步恢复交易和信任。贵重物资损失按照对应价值处理，不能用几根木棍直接抵消整箱钻石。

    聚落被严重破坏时也允许衰退，无法保证在一切人为破坏下仍自动恢复。

19. **后期城市规划从已有街道生长出来，重点逐渐转向生活品质。**

    整体发展可以划成以下状态，但升级条件由实际设施与资源决定：

    | 状态 | 主要问题 | 主要建设 |
    |---|---|---|
    | 营地期，约 8～12 人 | 活下来、建立生产 | 农田、仓库、基本住房、步道 |
    | 村落期，约 12～24 人 | 容纳家庭、稳定运输 | 扩建住宅、工坊、桥梁、石质道路 |
    | 成长期，约 24～48 人 | 分工、交通与防御 | 分仓、主街、公共空间、更高级傀儡 |
    | 成熟期，约 48～64 人 | 降低拥堵、提高品质 | 住宅改建、道路完善、庭院、景观与维护 |

    人口接近上限以后，建设预算逐渐转向修缮与品质。发生人口损失时，优先保障生存并补充人口，已有城镇布局保持连续。

    老建筑可以保留：第一座木桥旁出现新石桥，旧仓库改成商店，最早营火的位置成为广场。居民也可以给少量建筑赋予“历史保留”状态。

    后期的生活收益可以体现在更短的运输时间、更充足的休息、更稳定的生产和更少的拥堵。舒适度不会绕过人口上限。

20. **玩家需要能看懂聚落正在做什么，以及为什么停下来。**

    建议设置一块聚落公告牌，展示：

    - 成年人、儿童和待出生人口。
    - 当前人口上限与住房空位。
    - 食物还能支持多久。
    - 正在进行的工程和下一项计划。
    - 缺少的材料或工具。
    - 土地额度与外扩方向。
    - 傀儡数量、警报和玩家关系。

    查看某个居民时，显示简短状态，例如“给桥梁运送木板”“等待新镐”“回家吃饭”。

    查看工地时，能看到已完成阶段、缺少材料和停工原因。规划预览可以用地面标记展示未来房屋、道路与桥梁，玩家可以设置禁建方向和保护区域。

    玩家还可以提交“建议修桥”“这里适合农田”等提案。聚落根据人口、材料和路线判断是否执行，并给出原因。

    这些信息让玩家可以主动帮助，又能理解他们自主决定的过程。

21. **区块活动、保存与性能从设计阶段就设定边界。**

    日常生产、成长、繁衍和施工都依赖实际模拟。离开后不累计离线收益，重新加载时恢复原来的居民、库存和工地状态。

    必须处理城镇只有一部分正在活动的情况：

    - 不在活动区域内的居民仍计入人口上限。
    - 暂不可访问的箱子不能当作当前可领取库存。
    - 任务不会要求居民进入尚未活动的区域。
    - 跨越非活动区域的运输与工程暂停。
    - 聚落中心暂停时，停止新的全镇建设和繁衍安排。
    - 返回后重新检查现场，避免依据过期地形继续施工。

    人口名额、家庭关系、背包物品、已消耗建材、桥梁禁行状态和任务进度都需要保存，防止重进存档重复出生、重复扣料或复制资源。

    性能控制还包括：限制同时开工数量；共享已知道路；地形检查分批进行；库存变化时更新记录；失败任务等待一段时间再重试。

    建议同时开工数量从初期 1 项增加到成熟期最多 3 项。道路、桥梁和大型改建都算工程。

    **64 名居民和 8 个傀儡是设计起点，性能是否合适需要在你这套游戏环境里实测。** 测试要覆盖成熟城镇、复杂地形和多个聚落同时活动的情况。

22. **美术采用原创方块模型为主，免费资源作为素材与参考来源。**

    哥布林和自定义傀儡建议由我们统一设计轮廓、配色和动画。铁傀儡沿用原版，其余五级傀儡通过结构和材质表现区别。

    初期建筑偏木材、圆石和粗糙结构；中期出现明显工坊与机械部件；后期增加整齐石基、金属装饰、铺装道路和有秩序的街区。保留哥布林自己的风格。

    已查到可以纳入候选的来源：

    | 来源 | 已核实情况 | 计划用途 |
    |---|---|---|
    | [OpenGameArt：Goblin](https://opengameart.org/content/goblin-1) | 页面标为 CC0，提供带绑定与动画的 3D 模型 | 外形、动作参考或改造候选 |
    | [OpenGameArt：Pixelated Goblin](https://opengameart.org/content/pixelated-goblin) | 页面标为 CC0 的像素角色资源 | 配色、头像与像素表现参考 |
    | [Kenney](https://kenney.nl/support) | 官方说明资源页面上的游戏素材采用 CC0 | 界面图标、辅助素材与音效候选 |
    | [Blockbench](https://blockbench.net/wiki/blockbench/faq/) | 官方说明工具免费，制作者可使用和分发自己创作的作品 | 制作统一的方块模型与动画 |

    外部模型需要检查格式、风格和动画适配情况，再决定是否采用。资源来源、作者和许可随项目记录。这一轮只查找候选，不制作或导入成品。

23. **以后开发按可验证的闭环推进，最终覆盖上面的完整目标。**

    | 阶段 | 要完成的内容 | 验收标准 |
    |---|---|---|
    | 一：居民与资源 | 生物、职业、背包、真实箱子、工具、食物 | 8 名居民能够自行工作、吃饭、补种、存取物资 |
    | 二：家庭与住房 | 配对、出生、成长、人口上限、基础房屋 | 自行建房并养育下一代，人口不会超限 |
    | 三：土地与交通 | 人口土地额度、道路、木桥、玩家宅地 | 小人口不会无限圈地，居民能安全跨河，玩家房屋受到保护 |
    | 四：复杂建设 | 山地与其他地形、石桥、房屋改建、分仓 | 能根据地形调整，缺料停工后可以恢复 |
    | 五：防御与互动 | 六级傀儡、巡逻、维修、交易、偷窃关系 | 材料链贯通，守卫行为可理解，关系可以恢复 |
    | 六：成熟城镇 | 人口趋稳、品质升级、公共活动、性能调整 | 停止人口增长后，城镇仍能持续生活和改善 |

    完整验收还应包含以下场景：

    - 玩家完全旁观，聚落能够形成稳定生活。
    - 清空部分仓库，居民能够重新分工并恢复基础生产。
    - 桥修到一半缺料，没有居民走上未完工桥面。
    - 玩家在规划路线旁建房并圈地，工程重新选路。
    - 儿童集中出生时，人口和住房名额仍然准确。
    - 人口大幅减少后，城镇停止外扩并调整岗位。
    - 缺少黄金或钻石时，聚落仍能维持日常生活。
    - 在运输、孕育和施工途中保存退出，再进入后状态一致。
    - 达到人口上限以后，房屋、道路和公共空间继续改善。
    - 長时间运行后，没有持续增长的任务队列、物品堆积或重复实体。
