# 哥布林自治聚落：游戏内容计划

记录日期：2026-09-24  
状态：设计稿。`已定方向`来自用户明确选择；`建议初值`和玩法细节将在试玩后调整。

## 1. 核心体验与时间流动

玩家长期居住在哥布林聚落附近，能亲眼看见采集、运输、耕作、施工、繁衍、修路、架桥与居住环境改善。城镇变化具有可观察的因果：缺粮增加农活，住宅拥挤催生扩建，跨河资源值得利用时才建桥，交通量上升后才修整道路。

聚落日常由自己安排，玩家可旁观、交易、赠料、提供建设建议、保护居民，也能偷取公共箱子的物品并承担相应后果。聚落活动范围外暂停生产、成长和施工，玩家回来后从保存的状态继续。游戏运行不需要在线大模型替每个哥布林作决定。

发展循环：采集与种植 → 搬运入库 → 制作食物、工具和建材 → 修建住房与交通 → 支持出生和成长 → 增加劳动力 → 适度扩大生产。人口趋稳后转向维修、住宅改建、道路完善、公共空间与社交活动。资源充足时降低生产，避免无限堆积。

## 2. 营地生成与哥布林形象

初次满足选址条件时生成一个有固定身份的营地；重复进出区块不重复生成同一聚落。选址优先考虑安全地面、附近树木、水源和可耕地。**建议初值：8 名成年哥布林，男女各 4 名**，带营火、临时住所、公共箱子、少量口粮、种子、树苗、基础工具和铺盖。启动物资只发一次。其他自然营地的建议间距至少 512 格，多聚落共用可配置的世界人口预算。

先只做哥布林一个种族。成年男女共用基础骨架，脸形、发型、声音和少量衣饰有所区别，职业能力相同。儿童体型更矮，拥有玩耍、跟随和观察等动作，不承担危险采矿、战斗或繁衍。居民具有名字、家庭、住所、职业和简单的生活偏好；日常包含进食、工作、休息和在公共场所碰面。

## 3. 职业和任务调度

| 职业 | 主要职责 | 识别外观 |
| --- | --- | --- |
| 农民 | 耕作、收获、补种、采食、基础烹饪 | 草帽、锄头 |
| 林工 | 采伐、补种、管理林地 | 斧头、肩带 |
| 矿工 | 采石、开矿、勘查安全矿道 | 镐、头灯 |
| 建筑工 | 房屋、道路、桥梁、修缮 | 工具腰带 |
| 搬运员 | 仓储、工地供料、分仓运输 | 背包 |
| 工匠 | 工具、冶炼、维修、傀儡制造 | 围裙、护目镜 |
| 哨卫 | 巡逻、报警、引导避难、有限自卫 | 头盔、盾牌 |

初期允许兼职；人口、工坊和需求增加后再专业化。职业熟练度可以提高效率，转岗不剥夺基本工作能力。每位居民同时执行一个主要任务，工作位置和材料需要明确占用。哨卫负责警戒与组织，傀儡承担主要战斗。

默认优先级：避险救援 → 食物与补种 → 基础工具 → 关键交通和设施维修 → 必要住房 → 扩张工程 → 傀儡升级 → 装饰和品质改建。粮食不足时调回劳动力、暂停高价工程。失败任务记录原因并等待重新安排，避免居民反复撞墙或争用同一个箱子。

## 4. 自然繁衍、成长和上限

`已定方向`：通过成年哥布林正常繁衍增长人口。初期个体繁衍意愿强；中期成年人口更多，出生总量最高；后期意愿下降，满员后为零。孕育预占名额，避免同时出生越过硬上限。出生需要合适的成年伴侣、床位、食物储备和健康状态。儿童消耗食物与住房，成年后才提供劳动力和领地额度。

`建议初值`：单镇上限 64 人，含儿童和待出生名额。每分钟的全镇繁衍进度为：

```text
0.01 × 可参与的成年人口 × max(0, 1 − 已占用人口名额 / 64) × 生活条件系数
```

进度达到 1，安排一组符合条件的伴侣孕育一次。无合适伴侣时最多保留一次进度，避免条件恢复后集中出生。食物不足未来 30 分钟需求时生活条件系数为 0；食物覆盖未来 60 分钟并满足其他条件时为 1，中间平滑变化。

| 理想条件下人口与成年人数相同 | 意愿倍率 | 每 10 分钟繁衍进度增量 |
| ---: | ---: | ---: |
| 8 | 87.5% | 0.70 |
| 16 | 75% | 1.20 |
| 32 | 50% | 1.60 |
| 48 | 25% | 1.20 |
| 60 | 6.25% | 0.38 |
| 64 | 0% | 0 |

表格只表达趋势。真实出生速度受儿童比例、住房、食物和休养影响。建议孕育 10 分钟有效模拟时间，儿童成长 60 分钟，生育后家庭休养 30 分钟。保存退出、区块不活动、睡觉跳时间均不直接推进这些时钟。第一版暂不加入自然老死，战斗和事故可能造成死亡；人口低于上限后可以恢复繁衍。家庭记录双亲，并避开直系亲属和同父母兄弟姐妹配对。

## 5. 人口约束的领地

`已定方向`：人口少时不能无限圈地；儿童和傀儡不增加土地额度。发现资源点不自动取得沿途大量土地。扩张还需要食物、材料、交通和施工劳动力。人口损失时停止新增用地，已有房屋与道路继续存在。

`建议初值`：以 8×8 格为一个规划地块，最多允许 `4＋2×成年哥布林人数` 个地块；住房、道路、农田、工坊、林地与工作营地都消耗额度。下表是许可上限，不意味着全部开发：

| 成年人数 | 地块额度 | 对应面积 |
| ---: | ---: | ---: |
| 8 | 20 | 1,280 平方格 |
| 16 | 36 | 2,304 平方格 |
| 32 | 68 | 4,352 平方格 |
| 64 | 132 | 8,448 平方格 |

扩张优先使用现有空间。每 20 分钟最多新增 `成年人数÷8` 向下取整、且不超过 4 块地；距中心 96 格作为早期建议的开发距离上限。人口减少后可缓慢停用外围闲置设施，不自动拆掉村庄或玩家建筑。所有数值均需按实际地形与模拟距离试玩调整。

## 6. 真实库存、工具与生产闭环

成年居民建议有 6 格物品空间及工具、装备位置。主要储备在玩家能够打开、拿取和破坏的真实公共箱子中。工作流程：领取工具 → 前往工作地 → 采集或生产 → 装入背包 → 运往仓库或工地 → 实际存放或施工。仓库满时减产或增加合适容量，不能凭空消失物品。

聚落统计箱子中的实际物资，立项时预留，施工时逐批领取。玩家拿走材料会造成真实短缺，居民可补货、改派工作或暂停工程。已投入工地的材料和已完成方块需要有记录，重载后不能重复扣料或发料。库存目标达成后减产、休息与社交，避免无限砍树和堆物品。

| 链条 | 产出 | 保留的关键储备 |
| --- | --- | --- |
| 农业 | 作物、食物 | 下一轮种子和应急口粮 |
| 林业 | 木材、木板、木棍、木炭 | 补种树苗和基础木材 |
| 基础工具 | 木石工具、工作台、炉具 | 至少两套基础工具材料 |
| 冶炼 | 金属工具与建筑部件 | 采集工具与维修材料 |
| 建筑 | 房屋、道路、桥梁 | 关键设施应急维修材料 |
| 防御 | 傀儡与维护部件 | 现有守卫维修材料 |

工具具有耐久，出工前检查。全部工具损失时，居民可以低效地重新取得木材，再逐步恢复木石工具。砍伐后补种，收获后留种。金属和钻石矿产按真实储量消耗；缺少稀有材料时可勘查可达区域、降级生产或通过交易取得，日常生活仍能维持。

## 7. 建筑、道路与桥梁

住房按临时住所 → 基础木屋 → 扩建住宅 → 优质住宅 → 成熟街区住宅发展。容量升级与品质升级分开：人口满额后仍可改进屋顶、墙面、家具、庭院和街道。建筑由基础结构与可组合部件构成，选址时预留少量改建空间；改建前确认材料和临时住处，逐段施工。仓库、农田、工坊、厨房、巡逻点、广场和交易摊位按实际需求建设。早期旧仓库、营火和木桥可被保留并赋予聚落历史感。

道路连接住房、仓库、农田、工坊、资源点和桥头。先有安全通行路线，再根据频率与搬运耗时铺装和升级。路线考虑距离、坡度、危险、施工材料、耕地损失和玩家宅地；允许弯曲，减少无谓削山。建议通行净宽：初期步道 2 格，普通道路 3 格，成熟主街 5 格。堵塞时先考虑会车处、分仓和时间安排，再扩宽；大型傀儡有独立的宽度与高度约束。

桥梁是独立工程。先确认对岸有利用价值、两端能接入道路、桥基安全、材料与施工人员足够。建议木桥支持约 4～12 格跨度，改进的石桥支持约 12～24 格，具体以可验证结构和地形为准。施工顺序：两岸引道 → 桥台和支撑 → 桥面 → 护栏 → 照明 → 连通验收。未完工桥梁禁止通行；缺料后保留安全工地，损坏后先禁行再维修。初期重点覆盖河流、浅水和小峡谷。

## 8. 地形适应

| 地形 | 建设策略 |
| --- | --- |
| 平原 | 紧凑住宅，保留连续农田 |
| 森林 | 选择性伐木和补种，围树布局 |
| 河谷 | 优先同岸扩张，需求明确后跨河 |
| 丘陵、高山 | 小台地、台阶路、分层街区，限制大面积削山 |
| 沙漠 | 靠近水源，先保障粮食与木材，使用当地材料 |
| 雪地、冰川 | 保护耕作条件和通道，选择稳定陆地 |
| 沼泽 | 抬高地板、短栈道，避开深水 |
| 海岸、大海 | 沿陆地海岸发展，深海阻断陆路外扩 |
| 峡谷、熔岩、危险洞口 | 标记危险、绕行或封闭靠近路线 |

选址检查地面支撑、坡度、头顶空间、地下危险、道路入口和建设成本。缺少安全方案时允许换方向、缩小建筑或转向村内改造。

## 9. 守卫与六级傀儡

`已定顺序`：木 → 石 → 原版铁 → 金 → 钻石 → 黑曜石，黑曜石为最高级。

| 等级 | 主要定位 | 材料和外观方向 |
| --- | --- | --- |
| 木 | 初期巡逻、抵挡小威胁 | 木框架、基础核心 |
| 石 | 耐打的营地与工地守卫 | 石甲、厚重双臂 |
| 原版铁 | 稳定主力，需接入哥布林归属和警报规则 | 沿用原版外形和基础材料体系 |
| 金 | 更高级护卫，可支援附近同伴 | 金色结构、红石驱动核心 |
| 钻石 | 高攻击与机动，救援和追击 | 钻石护面、高级核心 |
| 黑曜石 | 最高综合战力，驻守聚落核心 | 黑色重甲、钻石核心，昂贵而较慢 |

金级高于铁级的理由是更高级的核心与工艺。建议每 8 名成年人约提供 1 个傀儡名额，至少 1 个、至多 8 个；黑曜石至多 1 个。哨卫按约每 12 名成年人 1 名、最多 4 名，哨卫属于人口。低级傀儡可继续承担次要职责；升级保留个体名字和归属。

进阶资源顺序：铁工具 → 钻石 → **先保留钻石镐** → 采黑曜石 → 制造最高级傀儡。工坊不得花光开采下一阶段所需的关键材料。傀儡损坏后回工坊维修，材料不足时调整巡逻。

玩家携带武器、路过仓库或住在旁边不会自动成为敌人。明确的攻击和严重破坏触发防卫。哨卫报警，非战斗居民与儿童避难；傀儡追击范围有限，优先保护居民，再保护关键设施。

## 10. 玩家宅地、偷窃和关系

提供低成本的“宅地界桩”：玩家用两个角登记矩形地块，可拼接多个区域，默认保护整个高度和少量边缘缓冲。聚落不得在保护区内拆放方块、挖矿、伐木、平地、改动液体、使用玩家箱子或占用土地。可单独授予通行、指定箱子使用和建设权限。规划与实际施工都检查同一保护规则，冲突后停工并改线。

新放置的玩家方块可被记录；已有容器、红石及疑似建筑应被避让。仅凭方块外观无法可靠判断旧建筑所有权，界桩是正式保障。玩家可在聚落内部登记房屋并允许道路接至入口。

公共箱子标注所属聚落。打开箱子不算盗窃，未经允许取走物品才进入判断。无人目击只导致物资短缺与加强巡逻；被目击的小额初犯先警告、允许归还；反复盗窃降低信任，暂停交易或驱赶；攻击与严重破坏触发守卫。交还或补偿相应价值的资源，再通过合作逐渐恢复关系。赠予箱与交易箱提供正常交互方式。

## 12. 区块活动、性能与验收

离开聚落后暂停实际生产、成长、孕育和施工。居民、人口名额、工具、库存、工地、土地、桥梁禁行状态和关系需要保存。部分区块不活动时，居民仍计入人口；不可访问的箱子不能当作可领取库存；跨越非活动区域的任务暂停。回来后重新检查地形与实际物资。工程、出生和材料扣除在重载后不得重复。

建议初期同时进行 1 项工程，成熟期最多 3 项；限制同时规划、找路和地形扫描的工作量。单镇 64 人与 8 傀儡只是性能预算初值，需要在成熟城镇、复杂地形和多个聚落同时活动时测量并调整。

最终要验证：完全旁观仍能稳定生活；仓库被偷后能恢复基本生产；缺料桥梁安全停工；玩家圈地后改线；出生与住房名额一致；人口下降后暂停外扩；稀有矿枯竭时维持日常；中途存档重进不复制资源或实体；人口封顶后继续改善村庄；长时间运行后没有不断增长的无效任务和库存。
